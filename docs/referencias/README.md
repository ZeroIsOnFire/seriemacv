# Referências de modelos de currículo

Esta pasta reúne referências para analisar estrutura, ordem de seções, densidade de
informação e regras de apresentação. Elas **não** são estilos distribuídos pelo
seriemaCV nem devem ser alteradas e apresentadas como templates próprios do
produto.

## Arquivos locais

| Arquivo | Padrão | Uso de referência |
| --- | --- | --- |
| `oxford-tradicional.pdf` | Oxford, cronológico reverso | CV conciso de uma página, com educação, experiência e competências. |
| `oxford-competencias.pdf` | Oxford, baseado em competências | Transição de carreira ou contexto em que competências transferíveis devem aparecer antes do histórico. |
| `oxford-academico.pdf` | Oxford, acadêmico | Pesquisa, ensino, publicações, financiamento e referências. |
| `brasil-govbr-modelo-curriculo.docx` | Brasil, Portal do Servidor | Formulário curricular brasileiro em Word, útil para observar campos e convenções locais. |

Os PDFs são cópias de materiais publicamente disponibilizados pela Oxford
University Careers Service. Confira os termos do site de origem antes de
redistribuí-los fora deste repositório ou incluí-los no produto.

## Regras que influenciarão os estilos do seriemaCV

- O conteúdo canônico é `career.yml`; referências não definem o modelo de dados.
- Estilos iniciais devem ser ATS-safe, em uma coluna, legíveis e ajustáveis entre
  A4 e Letter.
- O estilo Oxford tradicional é uma referência primária para a primeira projeção:
  hierarquia simples, experiência em ordem reversa, bullets curtos e foco em
  impacto.
- Currículo por competências e acadêmico são estilos/variações futuros, não
  substitutos do career.yml canônico.
- Nunca reutilize nomes, contatos, histórico profissional ou textos dos exemplos
  como dados de demonstração do produto.
- Trate os exemplos brasileiros como referência de convenções locais, não como
  requisito universal de campos, foto ou dados pessoais.
